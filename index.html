Binance Futures Terminal
Enter your API credentials to connect. Keys are stored only in your browser and sent directly to Binance — never to any third party.
⚠️ Security checklist before continuing:
• Delete any previously exposed keys on Binance
• Create a NEW API key with Futures Trading only
• Disable withdrawal permission on the new key
• Enable IP restriction (whitelist your IP)
🔒 Your keys are stored in browser localStorage only.
All API calls go directly to fapi.binance.com.

How to Serve Locally

1. Save this file as index.html
2. Open Terminal in that folder
3. Run: python3 -m http.server 8080
4. Open: http://localhost:8080

This avoids CORS issues when calling Binance API.

Deploy to GitHub Pages

1. Create a private GitHub repo
2. Upload this file as index.html
3. Enable Pages → main branch → / root
4. Access at: your-username.github.io/repo-name

⚠️ Never paste API keys in code you push to GitHub.
